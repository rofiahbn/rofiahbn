## Featured Project

### 📊 Credit Scoring Model to Reduce Default Rate

A machine learning project focused on improving credit risk assessment for an **NBFI vehicle loan portfolio**.

**What I worked on:**

* Cleaned and prepared a dataset containing approximately **118K loan applications**
* Performed exploratory data analysis and feature analysis
* Built and tuned an **XGBoost classification model**
* Used **SHAP** to interpret model predictions
* Developed an ETL pipeline using **Apache Airflow**
* Stored processed data using **PostgreSQL**
* Created data visualizations using **Tableau**
* Achieved approximately **0.745 ROC-AUC**
* Developed a threshold strategy to reduce the portfolio default rate

🔗 [View the project](https://github.com/CODA-Assignment-Bay/final-project-rmt-19-coda19-team-2)
